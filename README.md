# HibernateCRUD
This project shows a simple CRUD (Create, Read, Update, Delete) operations using Hibernate in a Java Maven project. 

## Requirements
1. Java
2. Intellij IDE or Eclipse
3. MySQL

## Java Installation
Download Java JDK from https://www.oracle.com/java/technologies/downloads/ and do the post install steps like the environment variable addition and all.
